# Semana 7 — Dashboard & storytelling

## Objetivo
Traduzir análise em **decisão**: dashboard operacional + 1-pager executivo.

## Como rodar
```bash
pip install -r requirements.txt
streamlit run dashboards/s05/app.py
```

## Estrutura do 1-pager
1. **Situação** — contexto + números-chave
2. **Insight** — o que os dados revelam (não o "como")
3. **Recomendação** — ações priorizadas
4. **Impacto** — esperado em R$/%

## Exercícios
1. Rode o dashboard no dataset real e capture screenshots.
2. Preencha `docs/s05/one_pager_template.md` com números reais.
3. Apresente em 3 min para "stakeholder" (grave-se).

## Entregável
- Dashboard funcional (`dashboards/s05/app.py`)
- 1-pager executivo preenchido
- Gravação de 3 min de storytelling
